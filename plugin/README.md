# English Reader（英语精读）

> 这份文档描述 `plugin/` 里的 bundle。功能总览和安装步骤见
> [仓库 README](../README.md)。

一个 DeepSeek Harness 客户端插件：导入电子书，逐句精读——**听朗读**、**跟着语音打字**、**朗读后与原文比对**。

全部能力都在页面里跑：文件不出本机，书存在浏览器 IndexedDB，语音用系统自带的 Web Speech API。

---

## 功能

| 能力 | 说明 |
|---|---|
| 导入 | 拖拽或点选导入 **EPUB / TXT / Markdown / HTML / PDF**；PDF 走懒加载 chunk，不拖慢首屏 |
| 书库 | 书架式首页：顶部分段导航（书库 / 精读 / 生词本）、**READ / PLAYED / READING SPEED** 三张统计卡、**缩略图网格**（默认）/ 列表切换、搜索；EPUB 封面自动抽出缩成小图，没有就生成占位封面 |
| 每本书的操作 | 封面左下角 🎧 直接朗读、右下角 ⋯ 菜单：**词频统计**（全书高频词条形图）、**查看详情**（作者/格式/章节/段落/词数/进度/已读词数/时长/加入时间）、**重命名**、**删除** |
| 阅读情况 | 书库顶部汇总：本书数、在读、**已读词数**、**累计时长**；每本书显示进度百分比与已读词数 |
| 整段展示 | 精读页永远显示**整个自然段**，段内句子全部可见；当前练习句高亮，其余句子淡出 |
| 练习范围 | 「逐句 / 整段」一键切换：逐句＝只练当前句；整段＝整段一起练（打字、朗读、跟读都跟着变） |
| 听读 | 朗读当前练习单元，按 word 边界高亮当前词；可调语速（0.5x–2x）与语音（只列英文语音）；可循环 |
| 打字 | **原位打字**（参考 Type to Learn）：段落本身是打字面，当前词高亮，打错的字符就地标红；顶部准确率/速度条，底部等宽词输入框；**语音跟随打字** |
| 朗读 | 调用语音识别，识别结果与练习单元做词级对齐，标出漏读 / 误读 / 多读；不支持识别时降级为录音回放 |
| 点词查词 | 点段落里任意一个词，弹出**词卡**：音标、词性、中文释义、例句（带翻译）、这个词在当前句子里怎么理解——由宿主已配置的大模型实时生成 |
| 生词本 | 词卡里 ★ 收藏；左侧抽屉可查看全部生词、环形进度（Known / Learning / To learn）、今日新增、搜索与分类筛选 |
| 间隔复习 | 新收藏的词立刻进入「待复习」队列；复习按 1/2/4/7/15/30 天递增排期 |
| 符号替换 | 打字设置里可配置「原符号 => 你实际敲的字符」（如 `—` => `-`），判定按替换后的目标进行 |

## 怎么看窗口是不是跑着旧 bundle

书库标题右边有一串**构建时间戳**（例如 `2026-10-25 16:59`）。桌面端不会自动重新加载插件的前端代码，所以改完代码后要 **⌘R 刷新**；时间戳对不上就说明窗口还是旧的。

## 页面出错的兜底

**页签内容**外面包了一层**错误边界**：某个区块渲染出错时，不再是一��空白，而是显示「阅读器遇到问题，停止了。」+「你的书和笔记都还在，重新加载一般就能恢复。」+ 具体的错误信息 + 一个重新加载按钮。

边界在**页签内容**这一层，不在整页：

- 顶栏（书库 / 精读 / 生词本）**始终可用**，崩溃了还能切走
- 只有出问题的那个区块被替换
- 崩溃页会显示**错误原文和出错的文件位置**，桌面端不用开 devtools 也能把原因报给我

## 界面约定（对齐 TingYue）

- **填充按钮**（播放/朗读/复习）hover 时保持填充，只轻微变暗；描边按钮 hover 才填浅灰；禁用态是灰底灰字。
- **生词本抽屉**只占插件自己的区域，不遮挡宿主界面；抽屉和页面两种形态共用同一套排版（进度环 + 三项统计 + 筛选 + 搜索）。
- **阅读页**按句分组但不断行；生词按状态上色，模糊模式下模糊落在词上（filter 不能作用于行内元素）。
- **阅读页左上角有「退出当前书籍」**：一个返回箭头，点了就回到书库（阅读时长在退出时落盘，不会丢）。
- **听读模式可以用键盘翻页**：`←` 上一句 / `→` 下一句（练习范围是"整段"时就是上一段/下一段）。切到打字模式后方向键让给输入框，界面里的提示行也会写明这一点。
- **朗读模式有兜底**：桌面端通常没有可用的语音识别服务，识别一失败就自动切换成「录音回放自评」，而不是给一条死路。
- **云端朗读有两层保险**：点播放时先用一段静音音频解锁播放权限（否则浏览器会在网络往返之后拒绝播放）；云端音频放不出来时立刻回落到本机合成。
- **阅读页高度自适应**：正文列宽用 `ch` 约束（书籍阅读的舒适行长），正文在面板内独立滚动，**打字输入框与播放条永远可见**（sticky），不被长文顶出屏幕。
- 工具栏用矢量图标，不用表情符号。

## 模式行是吸顶的

听读 / 打字 / 朗读、练习单位、填空、全文翻译这一行**固定在阅读区顶部**，正文滚动时它不动，控件永远够得着。

## 阅读页按窗口高度填充

阅读区不再是固定 6 段：它会**量一量窗口有多高，再决定放几段**（最多 40 段，最少 3 段）。窗口大就多放几段，小就少放，文字始终填满可视区，不留大片空白。

窗口尺寸变化时重新量一次——注意**不能**在尺寸变化时把页大小重置回去，那个更新会把"填满"的更新抵消掉（React 会把两次更新批成一次）。

页大小必须**收敛**：记住最后一个放得下的尺寸，一旦某个尺寸放不下就退回它并停止调整，否则文字会在读者眼前反复横跳。

## 组件里的 hook 必须在提前 return 之前

阅读器组件在没有书的时候会提前 return 空状态。**所有 hook 必须写在它前面**，否则两次渲染的 hook 顺序不同，React 的状态槽位会串位——表现是"状态明明改了，界面不动"。

## 书架上的按钮都要有反应

- 封面上的 **🎧** 是「朗读这一本」：打开书并**立刻开始朗读**（网格视图和列表视图都有效）
- 封面上的 **⋯** 打开菜单：词频统计 / 查看详情 / 生成封面 / 重命名 / 删除（**列表视图也渲染菜单**）
- 列表视图那一行另有「朗读 / 继续阅读 / 删除」三个按钮

## 数据库升级不会卡死

本地库升级版本时，**还开着的旧窗口会挡住升级**（浏览器的规则）。所以：

- 连接上挂了 `onversionchange`：别的窗口要升级时，这个连接主动让路 ✓
- 升级被挡住时**先重试一次**（旧窗口通常一秒内就关），还不行就报错「本地书库正被另一个窗口占用，请刷新页面」，**绝不无限等待**

## 阅读笔记

阅读页顶栏有一个**笔记按钮**（带条数角标），点开是一个对话框：

- 上面是**当前那句话**（斜体引文），下面是一个输入框，写完点「保存笔记」
- 下面是这本书已有的笔记：每条带原文引文、你的文字、时间
- 每条笔记有「跳到这句话」（回到原文的位置）和一个删除按钮

笔记存在**本地 IndexedDB**（数据库升到 v3，新增 `notes` 表，按书分组），刷新、重启都还在，不出本机。

## 在线书库（Project Gutenberg）

书库页顶栏的 🌐 按钮打开在线书库：按书名或作者搜索，点「获取」直接下载、解析并入库。

- **书源**：Project Gutenberg（公版书），用的是官方机器可读目录 `pg_catalog.csv`（约 21 MB）和官方下载直链
- **目录放在宿主**：目录太大，不进 bundle；宿主第一次用到时下载一次，缓存在 `~/.dsh/english-reader/gutenberg-catalog.csv`（七天过期），之后在内存里搜索
- **下载很稳**：连接经常被切断，所以每个文件都按 Range 分块下载并重试，失败时回退到分块路径
- **导入即干净**：公版书自带授权声明与扉页，导入时自动去掉（`stripBoilerplate`）

## AI 封面

书里没有自带封面的，让 MiniMax 画一张：

- 接口：`POST /v1/image_generation`，模型 `image-01`，比例 `2:3`（书的标准开本）
- 提示词只给**书名**（图像模型把长标题和作者名都会写错），并明确要求「只出现书名，不要作者名、不要出版社」
- 图片在宿主侧下载成 data URL 存进 IndexedDB，书架不依赖网络
- **书先入库、封面随后补上**：导入后立刻能看到书，封面几秒后自己换上；也可以在书的 ⋯ 菜单里点「生成封面」重画
- **画封面有反馈**：画的过程中书库里有一条「正在生成封面…」的提示，封面卡片上盖着一层转圈的遮罩；画完提示变成「封面已生成」，失败则说明失败原因（画一张要十几秒，不能让人干等）

## MiniMax 通道（语音 + 模型）

宿主半边持有 MiniMax 的 API Key，客户端通过 `/api/english-reader` 请求：

| 方法 | 作用 | 实现 |
|---|---|---|
| `status` | 通道是否可用 | `src/host/minimax.js` |
| `voices` | 英文系统音色列表 | `get_voice` 接口 |
| `tts` | 朗读一段文本 | `t2a_v2` 接口，返回 `data:audio/mp3;base64,…` 与时长 |
| `word` / `translate` / `breakdown` | 查词、翻译、拆句 | `chat/completions` 接口，模型 `MiniMax-Text-01` |

**Key 不进代码、不进 bundle**。读取顺序：

1. 环境变量 `MINIMAX_API_KEY`
2. 私有文件 `~/.dsh/english-reader/minimax.key`（权限 600）
3. 环境变量 `ENGLISH_READER_MINIMAX_KEY_FILE` 可改这个文件的位置（测试用它来关掉通道）

没有 Key 时：查词/翻译回落到宿主自己的模型，朗读回落到浏览器的 Web Speech API，学习者不会听到任何变化。

**引擎只报码，页面负责翻译**：识别/录音的失败在引擎里是机器码（`NO_RECOGNITION` / `RECORD_FAILED`），界面按语言给出人话，不再出现引擎里写死的中文串。

**朗读（Read aloud）也走 MiniMax**：桌面端拿不到浏览器的语音识别服务，所以朗读时**用麦克风录音 → 宿主转写 → 与原文逐词比对**，准确率、漏词、多词全部照常给。转写接口是 `POST /v1/speech_to_text`，模型 `asr-1.0`。宿主没配 key 时才回落到浏览器的 `SpeechRecognition`（多数桌面环境不可用），再不行就是纯录音回放自评。

**单词发音也走 MiniMax**（`src/lib/speech.js`）：点词、词卡上的喇叭、生词本里的喇叭，都先用云端音色念，失败才回落到浏览器自带语音。朗读整段用的是底部播放条上选中的音色；念单词时默认用选中的云端音色，没有就用第一个 MiniMax 音色。

**行为细节**

- 选中的音色带 `mm:` 前缀即为 MiniMax 音色；音色下拉里标着 `· MiniMax`
- 云端音频没有 boundary 事件，词的跟随高亮按**音频总时长平均分配**，比本机合成的固定节奏更准
- 云端合成失败（网络、额度、鉴权）自动回落到本机合成
- 这个 Key 对应的 API 根是 `https://api.minimaxi.com`，`api.minimax.io` 会拒绝它

## 封面与阅读速度的两个坑

- **列表视图的小封面**：两个圆形按钮（🎧 / ⋯）缩到 17px 并贴住下角，不会互相压住。
- **没有封面的书**：占位封面不是白板，而是一张渐变封面（首字母 + 一道细线），和真实封面放在一起不违和。
- **阅读速度的基线**：打开一本书时，**当前位置之前**的词不算你读过。少了这条基线，从中间打开的书会把前面几万词一次性算进阅读速度（出现过 10252 WPM 这种数）。另外速度超过 600 WPM 一律按"无数据"处理，不显示离谱的数字。

## 阅读页的结构（对齐 TingYue）

```
┌ 章节选择 ─ 段 1/2 · 句 1/3 ─ 书名 ── N 词 · N 待学 · est. N min · Known N% ─ 生词本 ┐
│ [听读][打字][朗读]   练习范围：[逐句][整段][填空]                    │  🖍 高亮   │
│                                                                            │  📖 释义   │
│  衬线正文的整个段落（生词黄底高亮，可开启词义注释）                          │  ␣ 填空   │
│                                                                            │  ⚙ 设置   │
├ 播放 ◀ ▶ 循环 ───────────── 语速 1x · 语音 Albert(en-US) · 1/2 ─────────────┤
```

- **全文翻译**：模式行上有独立开关「Full text translation」，打开后每段下方实时生成中文翻译（按页并行，一次模型延迟）。
- **顶栏的主次**：书名是标题（14px / 半粗 / 主色），段句位置是安静的说明文字（12px / 三级灰）；章节下拉有自绘的箭头，宽度封顶 200px。
- **提示语的位置**：阅读提示在正文卡片**内部的最上方**，不是浮在卡片外面；切到打字/朗读模式时它自动消失。
- **正文用衬线体**（书的样子），一屏显示**一整页（约 6 段）**：当前段是正文色，前后段落是上下文灰；翻句时当前段自动滚到视野内。
- **生词黄底高亮**：收藏过的词在正文里标黄；开「词义注释」后，释义以小字显示在词下方。
- **顶部进度条**：当前词数、待学词数、预计用时、已掌握比例。
- **目录**：书有多个章节时列章节；只有一章的书（长文）改为按段落列，每条带段落首句预览。
- **右侧竖排工具栏**：高亮生词 / 词义注释 / 填空 / 设置。
- **填空模式**：把这一段里你收藏过的词挖空，只练这些词。
- **底部播放条**：播放、上一句、下一句、循环、语速、语音、位置。

## 阅读页的结构

```
┌ 章节选择器 ── 第 3/12 段 · 第 2/4 句 ── 书名 ┐
│ 整个自然段（所有句子都在，练习句高亮、其余淡出）  │
│ [听读] [打字] [朗读]   练习范围： [逐句] [整段]   │
└ 练习面板（打字框 / 语音控制 / 识别结果） ────────┘
```

- **逐句**：当前句是练习目标，段内其它句子淡出作为上下文；「下一句」在段内推进，走完本段进入下一段。
- **整段**：整段都是练习目标；朗读一次读完整段，「下一段」跳到下一段。
- 顶部计数器始终同时给出「第几段 / 第几句」，不会丢失位置感。

## 打字模式（Type to Learn 模型）

段落本身就是打字面，不再另开一个大文本框：

```
62%   0 wpm   🔊  ⚙            ← 顶部状态条：准确率 / 速度 / 静音 / 设置
┌────────────────────────────────────────┐
│ The first fristraph opens the chapter.  │ ← 打错的字符就地标红
│ It carries three sentences so the       │ ← 段内其它句子淡出作上下文
│ reader can check the whole block at once.│
└────────────────────────────────────────┘
                ┌──────────┐
                │  frist   │               ← 底部等宽词输入框
                └──────────┘
```

- **逐词推进**：打一个词按空格提交并跳到下一个词；退格可以退回上一个词继续改。
- **打错就停在原地**：默认必须打对才能往下走（Type to Learn 的 "Forgive mistakes" 默认关闭）。
- **顶部状态条**：准确率（打对的字符 / 已打字符）、速度（词/分或字符/分，可切换）。
- **设置面板**（齿轮图标）：字体（无衬线 / 衬线 / 等宽）、字号、行高、速度单位、宽容错误、隐藏输入框。
  设置存在本机 localStorage，跟随浏览器。

## 书库与个人阅读情况

- **封面**：EPUB 的封面按「`meta[name=cover]` → manifest 的 `cover-image` 属性 → 阅读顺序里第一张图」的优先级取出，
  客户端缩到 320px 宽导出 JPEG（SVG 原样透传）；没有封面时按标题生成渐变 + 首字母的占位封面。
- **展示方式**：默认缩略图网格，右上角可切列表；选择存在 localStorage。
- **每本书的菜单**：词频统计、查看详情、重命名、删除；封面左下角的 🎧 直接朗读这本书。
- **朗读时长**（PLAYED）：播放语音期间单独计时，与阅读时长分开统计。
- **搜索**：书名、作者、格式，按书名或作者过滤。
- **阅读情况**：阅读时累计时长与已读词数（每 15 秒与每次翻句写回），按本地自然日分桶，
  书库顶部汇总本书数 / 在读 / 已读词数 / 累计时长，单书显示进度与已读词数。

## 点词查词怎么工作

1. 页面点词 → 客户端 `askAi('word', { word, sentence })`；
2. 客户端 POST 到宿主路由 `/api/english-reader`；
3. 宿主用 `ctx.agentDefaultModel.currentSelection()` 选模型、`ctx.llm.prepareCall()` + `prepared.stream()` 跑一次流式调用，要求模型**只输出 JSON**（解析失败自动重试一次）；
4. 词卡拿到 `{ word, phonetic, partOfSpeech, definition, examples[], contextNote }`。

宿主没配置模型、或调用失败时，词卡会显示中文错误，其它功能不受影响。
宿主路由在 `index.js`（插件的 Host 半边），**改 Host 半边需要重启 Harness 应用**才会生效；客户端半边刷新即可。

## 「语音跟随打字」的具体规则

打字模式默认开启「语音跟随打字」，同步逻辑在 `src/lib/engine/sync.js`：

| 你的打字进度 | 朗读的行为 |
|---|---|
| 落后于朗读 | **暂停**朗读，等你追上再继续 |
| 领先 1–2 个词 | 不动，让朗读自然跟上 |
| 领先超过 2 个词 | 取消当前朗读，**从你打到的位置重读** |
| 换练习单元 | 停止并复位，旧朗读的回调不会污染新单元 |

## 已知边界

- **扫描版 PDF** 抽不出文字，会明确报错，请改用 EPUB / TXT。
- **语音识别**依赖浏览器的 Web Speech API：在 Chrome / Safari 可用；部分 Electron 运行时没有可用识别服务，此时朗读模式会提示并降级为「录音回放」自评。
- **不派发 boundary 事件的浏览器**（Safari / Firefox）朗读高亮会退化为按词估算，精度略低但不影响使用。
- **MOBI / AZW3 / FB2** 等格式未支持（缺少可靠的纯前端解析器），导入时会给出明确提示。
- EPUB 章标题取正文首个 heading，其次取目录（TOC/NCX），最后退化为「第 N 章」。
